# logicberlin-collab.github.io

我的个人博客，记录学习、开发与生活中的思考。

## 长期栏目

- 学习笔记：记录概念、练习与待解决的问题。
- 开发手记：记录项目目标、实现过程与改进结果。
- 生活与思考：记录日常观察与逐渐形成的想法。

## 内容维护

页面使用纯 HTML 和内嵌 CSS，无需安装依赖或构建。文章保存在 `index.html`，使用 `<article>` 和 `<details>` / `<summary>` 展示。

新增文章时，填写唯一的文章 ID、栏目、实际发布日期、标题、正文及摘要，同步更新文章总数；需要时更新栏目入口。发布前检查页面结构、手机排版、键盘展开操作和页内链接，提交后确认 GitHub Pages 的线上页面已经更新。
